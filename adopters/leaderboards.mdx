Each board shows the top 100, and ranks only once it has at least three entries. Rankings are live, and a snapshot is taken every day at 03:00 UTC to award badges and send "you entered the top 100" notifications.

## How belief score is calculated

Belief score is the sum of three parts, added across every app you back.

**1. Each seat you hold**

```text
seat points = 100 / sqrt(seat number) / (tier position)
```

Tier position is 1 for Founding and 2 for Early, so the same seat number is worth half as much in Early. If the token has graduated, multiply by **3**. Withdrawn seats do not count.

**2. Each token you bought early**

```text
buy points = 100 / sqrt(your buy order)
```

If the token graduated, multiply by **3**. Then multiply by **1** if you still hold, or **0.25** if you have sold out.

**3. Your Contribution Points**

```text
CP points = 0.1 x lifetime CP
```

### Worked examples

| Case | Calculation | Points |
| --- | --- | --- |
| Founding seat #4, not yet graduated | 100 / 2 / 1 | 50 |
| Founding seat #4, token graduated | 50 x 3 | 150 |
| Early seat #4, token graduated | 100 / 2 / 2 x 3 | 75 |
| Bought 25th, still holding, graduated | 100 / 5 x 3 x 1 | 60 |
| Bought 25th, sold out, graduated | 100 / 5 x 3 x 0.25 | 15 |
| 278 lifetime CP | 0.1 x 278 | 27.8 |

The score updates nightly, and again the moment a token you hold graduates, so the tripling shows up right away. You appear on Top Believers as soon as your score is above zero.

<Tip>
  The square root means early matters most without becoming absurd: seat #4 is worth half of seat #1, and seat #100 is worth a tenth of it.
</Tip>

## The other boards

<AccordionGroup>
  <Accordion title="Trending score">
    ```text
    trend = (2 x log10(1 + volume in USD, last 24h) + 3 x log10(1 + unique traders, last 24h))
            x exp(-hours since last trade / 12)
    ```
    Volume and trader count are log-scaled so one whale cannot dominate, and the score fades with a half-life of about 8 hours since the last trade. Tokens with no activity in 24 hours drop off the board.
  </Accordion>

  <Accordion title="Closest to Graduation">
    Curve progress is measured in basis points, where 10,000 means the curve is full. Only live apps whose token is still on the curve appear, sorted from fullest down.
  </Accordion>

  <Accordion title="Most Backers">
    The count of members (every tier, including Public) of each live app. Ties are broken alphabetically by app slug.
  </Accordion>
</AccordionGroup>
